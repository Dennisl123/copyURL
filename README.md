# copyURL

NVDA add-on for copying URLs from web pages to the clipboard.

## How it works

Copy URL works on web pages only.

- Press Alt+Control+Windows+C to copy the current web page’s URL.
- Move to a link, then press Alt+Control+Windows+L** to copy that link’s URL without clicking or opening it.

## Settings

Open NVDA menu Preferences Settings Copy URL.

You can turn on or off the announcement that says the current URL or link URL was copied.

You can change either shortcut in NVDA menu Preferences Input Gestures Copy URL
